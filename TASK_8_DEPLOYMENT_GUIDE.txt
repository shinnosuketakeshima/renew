TASK 8: Deploy taiken-chat Edge Function to Supabase

PREREQUISITES
================================================================================

1. Supabase CLI installed locally

2. Active Supabase project with:
   - Project URL (e.g., https://your-project.supabase.co)

================================================================================
DEPLOYMENT STEPS
================================================================================

STEP 1: Install Supabase CLI
--------
macOS:
  brew install supabase/tap/supabase

Linux/Windows (via npm):
  npm install -g supabase

Verify installation:
  supabase --version

STEP 2: Login to Supabase
--------
supabase login

This will open a browser to authenticate. Copy the access token and paste in terminal.

STEP 3: Link to Supabase Project
--------
supabase link --project-ref your-project-ref

Find your-project-ref in:
  - Supabase Dashboard > Project Settings > General > Reference ID
  - Or extract from URL: https://your-project-ref.supabase.co

STEP 4: Set Environment Variables for the Function
--------
In Supabase Dashboard, go to: Project Settings > Functions > Add Secret

Add these secrets:
  SUPABASE_URL=https://your-project-ref.supabase.co
  SUPABASE_ANON_KEY=your-anon-key-from-api-settings
  GOOGLE_API_KEY=your-google-api-key-with-generative-ai
  LLM_PROVIDER=gemini

To find values:
  SUPABASE_URL: Project Settings > API > Project URL
  SUPABASE_ANON_KEY: Project Settings > API > Anon public key
  GOOGLE_API_KEY: Google Cloud Console > Credentials > Create API Key

Or use CLI to set secrets:
  supabase secrets set SUPABASE_URL "https://your-project-ref.supabase.co"
  supabase secrets set SUPABASE_ANON_KEY "your-anon-key"
  supabase secrets set GOOGLE_API_KEY "your-google-api-key"
  supabase secrets set LLM_PROVIDER "gemini"

STEP 5: Create Database RPC Function
--------
In Supabase Dashboard, go to: SQL Editor

Copy and run the SQL from:
  supabase/migrations/20260611_create_match_taiken_experiences.sql

The SQL creates the match_taiken_experiences RPC function used for vector search.

STEP 6: Deploy the Edge Function
--------
supabase functions deploy taiken-chat

Expected output:
  ✓ Function deployed successfully
    Endpoint: https://your-project-ref.supabase.co/functions/v1/taiken-chat

STEP 7: Verify Deployment
--------
Check Supabase Dashboard > Edge Functions > taiken-chat to confirm it's live.

================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: Function Deployment Fails
Cause: Not logged in or project not linked
Solution:
  supabase login
  supabase link --project-ref your-project-ref
  supabase functions deploy taiken-chat

ISSUE: 401 Unauthorized
Cause: Invalid or missing Authorization header
Solution:
  - Verify the anon key in Project Settings > API
  - Include exact key in Authorization header
  - Format: Authorization: Bearer exact-anon-key

ISSUE: 500 Internal Server Error
Cause: Missing environment variables
Solution:
  1. Go to Supabase Dashboard > Project Settings > Functions
  2. Verify these secrets are set:
     - SUPABASE_URL
     - SUPABASE_ANON_KEY
     - GOOGLE_API_KEY
     - LLM_PROVIDER

ISSUE: "No matching experiences found"
Cause: taiken_experiences table is empty or embeddings not populated
Solution:
  1. Run Task 4 to populate the table:
     python tools/vectorize_taiken.py
  2. Verify data exists (in Supabase SQL Editor):
     SELECT COUNT(*) FROM taiken_experiences;

ISSUE: Embedding API Error
Cause: Invalid or missing GOOGLE_API_KEY
Solution:
  1. Go to Google Cloud Console > Credentials
  2. Create a new API Key if needed
  3. Enable Generative AI API
  4. Update GOOGLE_API_KEY secret in Supabase
