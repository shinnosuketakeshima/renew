4. LLM_PROVIDER (Optional)
   - Value: "gemini" (default) or "deepseek"

5. DEEPSEEK_API_KEY (Conditional)
   - Required only if LLM_PROVIDER=deepseek
   - Source: DeepSeek API dashboard

================================================================================
TROUBLESHOOTING GUIDE
================================================================================

Issue: Function fails to deploy
  Cause: Not authenticated or project not linked
  Fix: supabase login && supabase link --project-ref [ref]

Issue: 401 Unauthorized when testing
  Cause: Invalid anon key in Authorization header
  Fix: Verify key from Project Settings > API > Anon key

Issue: 500 Internal Server Error
  Cause: Missing environment variables
  Fix: Set all 4 required secrets in Supabase dashboard

Issue: "No matching experiences found" response
  Cause: taiken_experiences table empty or no embeddings
  Fix: Run python tools/vectorize_taiken.py to populate table

Issue: "Embedding API error" in logs
  Cause: Invalid GOOGLE_API_KEY
  Fix: Create new key in Google Cloud Console, enable Generative AI API

Issue: "Unknown LLM provider" error
  Cause: Invalid LLM_PROVIDER value
  Fix: Set to "gemini" or "deepseek" in Supabase secrets
