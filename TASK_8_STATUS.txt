HOW TO DEPLOY (QUICK REFERENCE)
================================================================================

Prerequisites:
  1. npm install -g supabase
  2. supabase login
  3. supabase link --project-ref your-project-ref

Deployment:
  1. Set 4 environment variables in Supabase dashboard:
     - SUPABASE_URL
     - SUPABASE_ANON_KEY
     - GOOGLE_API_KEY
     - LLM_PROVIDER=gemini

  2. Run SQL migration in Supabase SQL Editor:
     - Copy from: supabase/migrations/20260611_create_match_taiken_experiences.sql

  3. Deploy the function:
     supabase functions deploy taiken-chat

  4. Test the endpoint:
     curl -X POST https://your-project.supabase.co/functions/v1/taiken-chat \
       -H "Content-Type: application/json" \
       -d '{"question": "スリランカについて"}'

For detailed instructions, see: TASK_8_DEPLOYMENT_GUIDE.txt
