なぜスリランカ、ネパールで英語を学ぶのか

個人レッスンであれば、自分のリクエストに応じたレッスンを受けることができますし、 先生との会話の中で間違いがあればその都度先生が修正してくれ、自分の弱点を早く克服することができます。

先生方は「日本人は英語の文法を学校で学んでいるものの、英語を話す練習をしていないから話せない」ということを十分理解していますので、皆さまがわかりづらい英語を話すことがあっても、何を話そうとしているのかを根気良く理解してくれ、正しい表現を教えてくれます｡

スリランカは長い間英国領だったため、英語が公用語の一つになっていますので、同じスリランカ人同士でもビジネスにおいては英語で会話をします。また、ビジネスに限らず、日常的に英語を使うことが当たり前なので、どこにいっても英語が通じます。

ネパールにおいては、英語が第一外国語になっており、多くの人が英語を話しますので心配はいりません。
（また、ご希望の方には、英語のレッスンに加えて、スリランカではシンハラ語、ネパールではネパール語のレッスンを受けることができますのでお申し付けください。）

発展途上国であるスリランカ、ネパールは、自国の文化が非常に色濃く、ホームステイでは、先進国とは全く違った生活習慣や食文化を体験することができます。
スリランカでは、いまだに洗濯機のない家庭があり、ガスを節約するため薪で火をおこし食事を作っています。
穏やかで温かなスリランカ、ネパールのホストファミリーとの生活の中で、きっと不思議だらけの経験をすることになるのではないでしょうか。

文明社会をひと昔前に巻き戻したようなゆったり時間のスリランカ、ネパールは先進国では得られない味があります。

Beインターナショナル・留学プログラムでは、皆さまの未知なる経験の中でご自身の可能性を再発見されるようお手伝いさせていただきます。
