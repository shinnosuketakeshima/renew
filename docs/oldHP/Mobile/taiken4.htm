スリランカ・ネパールで英語を学ぶプログラム

体験者の声

■スリランカ：佐藤晴也様2004年9月ご参加

「いろいろとご対応ありがとうございました。
お陰様でとても有意義な旅ができたと思っております。

この旅において、いろいろな人と出会い、文化の違いを体験し、自分なりに考えることも多かったと思います。

このプログラムは値段的にリーズナブルだったことと、観光旅行は好きではないので、ホームステイやボランティア活動的な旅行をしたいと思って参加をしました。


ホストファミリーの方々、サーンタさんはじめ皆様には、大変お世話になりました。
今までインドやネパール等でホームステイをしましたが、スリランカでの食事は、思ったより辛かったです。
ワヤンバ職業訓練校でのボランティアやヒッカドゥアに行ったこともあり、ホームステイ先での滞在日は少なかったのですが、楽しかったです。

買い物に同行したり、バスの乗り方を教えてもらったり、洗濯をしてもらったりして助かりました。

スリランカは、思っていた以上に暑く、湿度がありました。

気に入った点は、物価が安く、フルーツがおいしかったこと、気に入らなかった点は、時間にルーズなところです。

列車などは朝早く 起きて行ったのに１時間遅れで駅にきました。

それでも乗車客からは 特に不平もないようです。
スリランカは、日本と違い時間厳守という文化ではないのでしょう。

急なスコールもしばしばあり、時間通りというのが難しいのだと思いました。

現地の人を日本の慣習にあわせさせるのではなく、こういう文化だということで、日本人がそれにあわせるのがホームステイかと思います。

その他、特に困った点もなかったのですが、あげれば、蚊にかなり刺されたくらいでしょうか。

不思議なのは、現地の人は何でもないのに、自分だけ刺されたことです。虫除けスプレーを持っていきましたが、虫除け対策は十分に必要です。


また、是非スリランカに行きたいと思います。
ワヤンバ職業訓練校でのボランティアにもまた参加したいと思います。」
