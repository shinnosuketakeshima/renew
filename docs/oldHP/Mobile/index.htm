なぜスリランカ、ネパールで英語を学ぶのか

日本人が英語を話せないのは「英語を話す機会が無い」「英語を話す練習をしていない」からです。
しかし、英会話学校に通うには多大な費用がかかります。
Beインターナショナル・留学プログラムでは、物価の安いアジアに目を向け安いレッスンを提供しています。

しかも全て個人レッスン！

スリランカ

スリランカってどんな国？

スリランカという国の名前を聞いて、どういう国かすぐ思い浮べられる人は、 少ないかも知れません。
それぐらい、あまり馴染みのない国かも知れません。・・・

レッスンについて

レッスンでは実際のコミュニケーションで役立つように、コミュニケーションスキル、リスニングスキル、ボキャブラリーアップを目的とし、加えてライティングスキル、リーディングスキルとグラマーをアップするためのレッスンを行っています。・・・

ホームステイについて

皆さまの滞在なさるホームステイ先は基本的には､ギリバッゴダ地域（コロンボ郊外）の中流クラス以上のご家庭になります｡
ホームステイ先のホストファミリーは必ずしも全員が英語を話せるとは限りませんが英語を話せるご家族の多いご家庭を選出しています｡ ・・・

低開発村視察

コロンボから､約100km離れた村を視察に行き､村の方々と交流をします｡
いまだにガスや水道､電気のない村がめずらしくありません｡・・・

ネパール

ネパールってどんな国？

ネパールは、インドと中国（チベット）に挟まれたところにあります。
その為、インド文化・チベット文化双方のの影響を受けています。・・・

レッスンについて

皆さまの英語教師をする先生は､ネパール人英語教師（週5回・1日4時間）の先生になります。
どの先生方も､英語を教えることの経験が豊富な方ばかりですので､ご安心ください。・・・

ホームステイについて

皆さまの滞在なさるホームステイ先は、基本的には、カトマンズ地域の中流クラス以上のご家庭になります。
ご希望の方には大学教授や経済学博士、研究者のお宅でのホームステイをご紹介しています。・・・
