# FTP デプロイ（本番用ファイルの区別）

このリポジトリは**公開サイトのURL構成（ルート直下に `index.html` 等）**のまま置いてあります。本番サーバのドキュメントルート（例: `public_html`）に **そのままの相対パス** で置く想定です。

## アップロードする（＝本番に含める）

次の**ディレクトリとファイル**を、サーバの公開ルートに上書き・追加します（`.git` は不要）。

| 場所 | 内容 |
|------|------|
| リポジトリ**ルート** | `*.html`（全ページ。体験談・料金・旧リンク互換用も含む） |
| `assets/` | CSS・画像等（必須） |
| ルート直下のメディア | 各ページ `src` で参照している `.jpg` / `.JPG` / `.gif` / `.png` 等 |
| 必要に応じて | サーバ上で従来使っている `images/` 等の**既存のフォルダ**（新サイトから参照が残っている場合） |

> 実際のファイル一覧の抽出には、リポジトリルートで `.\tools\list-deploy-files.ps1` を実行し、`tools\last-deploy-list.txt` を参照できます（`docs` / `tools` 等の除外入り）。

## アップロードしない（＝倉庫用・作業用）

| 場所 | 内容 |
|------|------|
| `docs/` | 設計書、旧サイト保管、メモ。本番では不要。 |
| `tools/` | 再生成スクリプト、デプロイ用リスト。本番では不要。 |
| `.cursor/` | エディタ用。本番では不要。 |
| `.git/` | バージョン管理。本番では不要。 |
| ルートの `README.md` | GitHub 用。通常アップロード不要。 |
| このファイル | 運用メモ。アップロード不要。 |

## 運上の注意

- 体験談索引 `taiken.html` を再生成する場合: `python tools/rebuild_taiken_index.py`（上書き前に中身の確認推奨）。
- 大容量の一括上書きは、バックアップ取得後、オフピークの時間帯を推奨。
