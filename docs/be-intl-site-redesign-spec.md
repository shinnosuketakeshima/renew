### 1-2. リニューアルの背景

現サイトは2004年の設立当初から大きなリニューアルが行われておらず、以下の問題が深刻化している。🔵

- HTMLがテーブルレイアウト（1990年代の手法）で構築されており、スマートフォンに非対応
- ファーストビューに問い合わせへの動線がなく、機会損失が発生している
- ナビゲーションが2層構造で役割が不明確
- ヒーローコピーに誤字（「可能性を再発見す**性**旅へ」→「する旅へ」）
- ネパール情報がスリランカに比べて薄く、目標配分と現状の乖離がある

### 1-3. リニューアルの対象範囲

- 全ページのデザイン・マークアップ刷新（レスポンシブ対応含む）
- 情報設計・サイトマップの再構築
- コンテンツの整理・加筆・誤字修正
- 資料請求フォームのデザイン統一
- SEO対策（URLリダイレクト設計含む）
- アクセス解析タグの設置

## 3. リニューアルの目的と目標

### 3-1. 事業目標

| 指標 | 現状 | 目標 |
|------|------|------|
| 年間参加者数 | 6〜7名 🔵 | 20名 🔵 |
| 月間問い合わせ数（逆算）| 3〜4件（推定）| 約11件 |
| 問い合わせ→申込み転換率 | 約15% 🔵 | 15%を維持（転換率は本人の情熱量に依存するため施策での改善は優先しない）🔵 |
| 国別目標配分 | スリランカ70%・ネパール30% 🔵 | スリランカ8名・ネパール12名 🔵 |

> **ギャップの解釈：** 現在の月間問い合わせ数（約3〜4件）を約11件に増やす必要がある（約3倍）。現状がモバイル非対応・CTAなしという状態であるため、基本的な整備だけで大幅な改善が見込める。

> **ネパールについて：** 現状の問い合わせ比率はスリランカ70%・ネパール30%だが、目標はネパール60%と逆転する。リニューアルでネパールの存在感を高めることが目標達成の直接的な鍵になる。

### 3-2. サイトの目的

**一次目的（コンバージョン）**

資料請求フォームへの誘導を最優先とする。

```
訪問者の行動フロー（確定）

サイト閲覧 → 強みの理解・信頼形成 → 資料請求フォームから送信 → メールで返信
                                                                         ↓
                                                          （必要な場合のみ）
                                                          やり取りの中で面談を提案
```

**二次目的（信頼形成）**

競合との差別化2点をサイト全体で一貫して伝える。

| 強み | サイト上での伝え方 |
|------|----------------|
| 価格の安さ | 料金表の数字（7日間92,000円〜）を前面に出す。比較データがないため欧米留学との比較数字は掲載しない 🔵 |
| 全コースマンツーマン | ヒーロー・強みセクションで最優先で訴求する |

### 3-3. 優先順位

**最優先**

1. スマートフォン対応 ── 情熱のある検討者がモバイルで来たとき離脱させない
2. 資料請求フォームへの動線確保 ── 月間11件を目標に全ページにCTAを設置する
3. 強みの明確な訴求 ── 「安さ」と「マンツーマン」をファーストビューから一貫して伝える
4. ネパールの情報量・訴求をスリランカと同水準に引き上げる

**高優先**

5. ナビゲーションの整理 ── 両国を対等に扱う構造にする
6. 体験者の声・参加者レポートの整理・可視化
7. 誤字・崩れの修正
8. SEOリダイレクト設計

### 3-4. 今回は対象外とすること

| 項目 | 理由 |
|------|------|
| SNS・LINE・各種ソーシャル連携 | 利用しない方針 🔵 |
| 多言語対応（英語ページ等）| 対応しない方針 🔵 |
| tel:リンク（タップで即発信）| 1名運用のため不意の着信負荷を避ける 🔵 |
| 面談のサイト上への掲載 | やり取りの中で代表者が必要に応じて提案する 🔵 |
| オンライン説明会・一般公開の予約フォーム | 1名運用での負荷が高い 🔵 |
| ブログ・コラムコンテンツ | 1名運用では継続更新が難しい 🔵 |
| 法人・公的機関向けの訴求 | 個人向けを中心に据える。問い合わせが来た場合は個別対応 🔵 |
| 転換率の改善施策 | 転換率は情熱量次第。問い合わせ数の増加を優先する 🔵 |
| Q&Aの検索・絞り込み機能 | コンテンツ整理を先に行えば不要な範囲 |
| 費用シミュレーター | 料金表の整備で代替できる |

## 4. ターゲットユーザー

### 4-1. 第一ターゲット

**30〜40代・女性・一人参加 🔵**

実際の申込みで最も多い層。

| 項目 | 内容 |
|------|------|
| 状況 | 会社を辞めたタイミングで参加するケースが多い 🔵 |
| 参加スタイル | ほぼ一人参加（一人参加を推奨）🔵 |
| 希望国 | スリランカを希望することが多い 🔵 |
| 情報収集 | PCとスマホ両方。口コミ・体験談を重視して時間をかけて比較検討 🟡 |

**この層の悩み**
- 一人で知らない国に行くことへの不安（安全性・ホームステイ先の環境）
- 英語力が低いまま申し込んでいいのかという不安
- 費用総額が見えない（航空券・保険を加えると）
- 人生の節目での決断。失敗したくない

**最初に知りたい情報**
- 費用の総額感（航空券・保険込みでいくらかかるか）
- 安全性・ホームステイ先の雰囲気
- 同属性（30〜40代・女性・一人参加）の体験者の声

**問い合わせ動機**
- 同属性の体験者の声を読んで「自分にもできそう」と感じたとき
- 費用感が見えて踏み切れたとき
- マンツーマンなら自分のペースで学べると確信できたとき

**訴求ポイント**
- 30〜40代・女性・一人参加の体験者の声を最優先で前面に（全体の約40%あり）🔵
- ホームステイ先の雰囲気を写真・エピソードで丁寧に伝える
- 「一人参加を推奨」と明示する
- マンツーマンであることの安心感を伝える

## 6. トップページ構成

> **設計の軸：** 「情熱を持って検討している人を途中で離脱させない」。スクロールするごとに不安が解消され、自然に資料請求へたどり着く流れ。

### SECTION 1 ── ファーストビュー

**伝えること：** 「誰のためのサービスか」「何が違うのか」を3秒で伝える。

| 要素 | 内容 |
|------|------|
| 背景画像 | 現地でのレッスン風景またはホームステイ先の写真。一人参加の女性が映るものを優先 🟡（素材確認要）|
| メインコピー | 「アジアで、一人で、マンツーマンで。本気の英語留学。」（案）🟡 |
| サブコピー | スリランカ・ネパール　21年・全コース個人レッスン |
| CTA | 「資料請求はこちら」ボタン |
| 電話番号 | 番号のみ表示（tel:リンクなし）🔵 |

### SECTION 2 ── 安心材料

**伝えること：** 「信頼できる会社である」ことを数字で即座に伝える。

| 要素 | 内容 |
|------|------|
| 表示形式 | 数字を大きく見せるカウンター形式 |
| 掲載する数字 | 創業21年 / 参加者13歳〜73歳 / 全コースマンツーマン 🔵 |
| 補足 | 公的機関の語学研修での採用実績あり（信頼性の文脈で一言のみ）🔵 |

### SECTION 3 ── 国を選ぶ

**伝えること：** スリランカかネパールか、2カ国の違いをひと目で伝える。

| 要素 | 内容 |
|------|------|
| 表示形式 | 写真カード2枚横並び（スマホ時は縦積み）|
| スリランカ | 海・英語公用語。写真は海またはホームステイ先 |
| ネパール | ヒマラヤ・異文化・ボランティア。写真は山の風景または現地の様子 |
| 各カードのCTA | 「スリランカを詳しく見る」「ネパールを詳しく見る」|

### SECTION 4 ── サービスの特徴

**伝えること：** 競合との差別化2点を中心に「なぜここなのか」を納得してもらう。

| # | 特徴 | 説明 |
|---|------|------|
| 1 | 全コース個人レッスン | グループレッスンなし。1日4〜6時間、自分のペースで 🔵 |
| 2 | 圧倒的なコスパ | 7日間92,000円〜 🔵（欧米留学との比較数字は掲載しない）|
| 3 | ホームステイ形式 | 現地の家族と暮らす本物の英語と文化体験 🔵 |
| 4 | 24時間現地サポート | 日本語対応。何かあっても一人じゃない 🔵 |
| 5 | 一人参加を推奨 | 一人だからこそ、マンツーマンが活きる 🔵 |

表示形式：アイコン付きカード5枚。スマホ時は縦積み。

### SECTION 5 ── 体験者の声ピックアップ

**伝えること：** 「自分と近い属性の人が参加してどんな体験をしたか」を見せる。

| 要素 | 内容 |
|------|------|
| 表示形式 | 体験者カードを3枚ピックアップ |
| 優先する属性 | 30〜40代・女性・一人参加 🔵 |
| カードの内容 | 氏名イニシャル・年代・参加国・参加期間・一言コメント |
| リンク | 「体験者の声をもっと見る」→ /voices/ へ |

### 7-0. 国別と横断：共通コンテンツの扱い

**両国に共通のテーマ**  
- **体験**（現地の過ごし方のイメージ）、**ボランティア**、**参加者レポート**、**24時間日本語の現地サポート**、**受入枠組み（安心の伝え方）**は、スリランカ・ネパール**いずれのプログラムでも共通**のサービス内容として扱いうる。  
- **現地受入団体の名称・事実**は**国ごとに異なる**：**スリランカ＝JASRI**、**ネパール＝ICEDC**（International Culture Exchange and Development Center）🔵。国別ページでは**相手国の団体名を誤って出さない**。国別は**国に固有の地の文脈**（景観・生活リズム・受入先の雰囲気等）に沿った**要約・例示**を載せ、**同じ枠組みの説明が両国で矛盾しない**よう整理する（**共通定義＋国別差分**を前提にする）。

**体験者の声**  
- 国別ページ（`/srilanka/` / `/nepal/`）では**厳選**（2〜3件程度でよい。第一ターゲット優先表示も可）。  
- 厳選に含まれなかった**体験談も、最終的にサイト上のどこかで閲覧できる**こと。実装方針として **`/voices/`（体験者の声）で全件に到達可能な一覧＋各詳細**とし、国別の「体験者の声をもっと見る」等の導線は**常に当該アーカイブ**へ通す。遺漏のない導線を優先する。

**参加者レポート**  
- 国別では**1件前後のアコーディオン**等の**抜粋**でよい。  
- **全レポート**も同様に、**専用の一覧・詳細**（例：`/voices/` 内のレポート節＋子ページ、または将来 `/reports/` 等。URL は運用に合わせる）で**掲載分すべてが閲覧可能**なこと。国別の「他のレポート」系リンクは**当該一覧**へ通す。古い年号の**掲載可否・表現**は従来どおり **TODO／事務局確認**。

**ボランティア**  
- **本丸**は **`/volunteer/`**（6種の説明は両国共通で実施）。国別は**要点＋ `/volunteer/` へ**のリンクで足りる。  

**受入団体・サポート**  
- **24時間日本語**・**受入の枠組み**の**説明の核**は、国別の「現地サポート」ブロックと、必要なら**国別の参照**（**スリランカ→`jasri` 系**、**ネパール→`nepal.html`（ICEDC）アンカー**）に整理した**横断・FAQ 補足**で足す。国別に**同趣旨の長文を二重掲載**しないよう、**参照先を一本化**する（旧 `icedc.html` は統合済み）。

## 8. デザイン方針

> **方針の軸：** 「派手さよりも、安心して読める。読んでいるうちに信頼が積み上がる。」

### 8-1. 全体トーン

| 目指す印象 | 避ける印象 |
|-----------|-----------|
| 落ち着いていて読みやすい | にぎやかで目が泳ぐ |
| 誠実で情報が正直 | 過剰な煽りや大げさな表現 |
| 温かみがある | 冷たく無機質 |
| シンプルで迷わない | 要素が多くて疲れる |

旅の高揚感は写真で表現し、テキストやUIは落ち着いたトーンで統一する。「写真が語り、テキストは補足する」という役割分担を意識する。

### 8-2. 色の方向性

| 役割 | 内容 | 理由 |
|------|------|------|
| ベース | 白・オフホワイト | 清潔感・余白の確保 |
| メインカラー | 深緑系（フォレストグリーン）| 自然・安心・誠実さ。両国の自然と親和性が高い |
| アクセント | テラコッタまたはゴールドイエロー（1色のみ）| CTAボタン・重要な数字に使用 |
| テキスト | チャコールグレー（黒に近い）| 長文でも読みやすい |
| 補助 | ライトグレー | セクション背景の切り替えに使用 |

**使ってはいけない色：** 蛍光色・ビビッドな原色・赤・4色以上の使用

### 8-3. フォントの方向性

| 用途 | 方向性 | 候補 |
|------|--------|------|
| 日本語本文 | 可読性の高いゴシック体 | Noto Sans JP・游ゴシック |
| 日本語見出し | 本文と同系統でウェイトで差をつける | 同上・Boldウェイト |
| 英語・数字 | シンプルなサンセリフ | Inter・DM Sans |

**フォントのルール**
- 本文サイズは16px以上（シニア層への配慮）
- 行間は1.8以上
- 見出しの大きさは3段階まで
- 装飾的な筆記体・明朝体は使わない

### 8-4. 写真の方向性

**優先する写真**

| 場面 | 方向性 |
|------|--------|
| レッスン風景 | 1対1で教師と向き合っている様子。笑顔があると良い |
| ホームステイ先 | 家族と食卓を囲む・会話している場面。生活感のある温かさ |
| 現地の風景 | スリランカは海・緑・青空。ネパールはヒマラヤ・山岳風景 |
| 参加者 | 30〜40代・女性・一人参加の様子を優先 |
| ボランティア | 現地の子どもや人々と関わっている場面 |

**写真の処理ルール**
- フィルターや過度な加工はしない
- 明るさ・コントラストの微調整程度にとどめる
- テキストを重ねる場合は薄いオーバーレイを使用する
- スリランカとネパールの写真が混在するページは作らない

**避ける写真**
- モデルを使った演出感の強い写真
- 観光地の定番カットのみで構成すること
- 2カ国の写真が同一ページで混在すること

### 8-5. 余白感

| 項目 | 方針 |
|------|------|
| セクション間 | 広めの余白を取る。区切りは色より余白で表現する |

### 8-6. 避けるべき表現

**ビジュアル面**
- バナー広告的なデザイン（色の氾濫・囲み枠の多用）
- アニメーションの多用
- グラデーションの多用

**テキスト面**
- 「！」「今すぐ」「絶対」「最安値」などの煽り表現
- 根拠のない比較（「業界最安」「No.1」）
- 過剰な太字・赤字
