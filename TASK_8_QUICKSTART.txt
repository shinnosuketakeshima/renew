================================================================================
COMMON ISSUES & FIXES
================================================================================

Deployment fails:
  → supabase login && supabase link --project-ref your-ref

401 Unauthorized when testing:
  → Check anon key in Authorization header (Project Settings > API)

500 Internal Server Error:
  → Verify all 4 secrets set in Supabase dashboard

"No matching experiences found":
  → Run: python tools/vectorize_taiken.py
  → Verify: SELECT COUNT(*) FROM taiken_experiences; (in SQL Editor)

Embedding API error:
  → Create/update Google API Key
  → Enable Generative AI API in Google Cloud Console

================================================================================
WHAT THE FUNCTION DOES
================================================================================

1. Takes a question in Japanese
2. Converts it to a vector (embedding)
3. Searches taiken_experiences table for similar experiences
4. Builds context from top 5 matches
5. Generates a response using Google Gemini or DeepSeek
6. Returns answer + source citations

Response time: 3-6 seconds (normal for AI generation)

================================================================================
ARCHITECTURE
================================================================================

RAG Pipeline:
  Question
    ↓
  [Embed via Google Generative AI] → 1536-dim vector
    ↓
  [Search via Supabase pgvector RPC] → Top 5 matches (cosine similarity)
    ↓
  [Build context from results]
    ↓
  [Generate response via LLM] → Gemini or DeepSeek
    ↓
  [Return answer + sources]

Performance:
  - Embedding: ~500ms
  - Search: ~100ms
  - LLM generation: 2-5 seconds
  - Total: 3-6 seconds
